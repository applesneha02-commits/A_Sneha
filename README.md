---

## ✦ Design System & Brand Identity

- **Color Palette:**
  - Obsidian Black (`#090909`) & Deep Charcoal (`#141212`)
  - Burgundy (`#4B101E`) & Muted Crimson (`#A92843`)
  - Dusty Rose (`#C58D9C`), Soft Blush (`#E5C6CE`), & Warm Ivory (`#F2EDE9`)
- **Typography:**
  - Headings: `Bebas Neue` & `Oswald` (Impact condensed editorial display)
  - Body: `Inter` / `Manrope` (Clean, legible high-contrast grotesque sans)
  - Editorial Accents: `Playfair Display` & `Cormorant Garamond` (High-fashion serif)
- **Visual Composition:**
  - Oversized background typography (`PORTFOLIO`) overlapping Sneha's portrait
  - Asymmetric editorial balance with thin crimson & rose dividers
  - High-contrast card layouts, interactive project modals, and certificate lightbox

## ✦ Tech Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite 5
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Icons:** Lucide React
- **Animations:** Framer Motion

## ✦ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/applesneha02-commits/A_Sneha.git

# Navigate into the project directory
cd A_Sneha

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Typecheck and build for production
npm run build

# Preview production build locally
npm run preview
```
